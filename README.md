TP 6 y 7 - Control de entradas y salidas con Arduino y Processing

Alumno: Ignacio Viera

-Descripción

El presente trabajo práctico consiste en desarrollar una interfaz gráfica en Processing para visualizar y controlar las entradas y salidas de una placa Arduino UNO.

El sistema permite visualizar el estado de dos pulsadores físicos mediante indicadores de colores y controlar dos LEDs desde la interfaz gráfica. También permite que los pulsadores físicos controlen los LEDs.

La comunicación entre Arduino y Processing se realiza mediante comunicación serie bidireccional.

Componentes utilizados

- Arduino UNO.
- Protoboard.
- 2 pulsadores.
- 2 LEDs.
- 2 resistencias de 1 kΩ.
- Cables de conexión.
- Cable USB.
- Cables tipo Jumper

Organización del repositorio

- Arduino: código fuente y descripción del programa Arduino.
- Processing: código fuente y descripción de la interfaz gráfica.
